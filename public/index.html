Spielen

So funktioniert's

  1. Lade unter Bilder verwalten deine eigenen Bilder hoch und ordne sie Kategorien zu.
  2. Erstelle einen Raum und teile den 4-stelligen Code mit deinen Freunden.
  3. Als Host stellst du ein: Anzahl Runden, Zeit, Tippen oder Multiple-Choice, und welche Kategorien/Bilder vorkommen.
  4. Bild wird angezeigt → wer am schnellsten richtig ist, bekommt die meisten Punkte.
